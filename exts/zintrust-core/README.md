# ZinTrust Core

Primary VS Code extension for ZinTrust projects.

Current scope:

- Explorer sidebar for core project shortcuts and workflows.
- Status bar entry that opens the dashboard from any workspace view.
- Dashboard webview for README, routes, database config, CLI docs, QA, and scaffolding actions.
- Helper-aware autocomplete for common `@helper/index` imports such as `isNull`, `isObject`, and `isMissingLike`.
- QA command entrypoint.
- Resource creation command entrypoint.
